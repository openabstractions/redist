OpenAbstractions user runtime

This package installs programs into ~/.local/bin and registers a LaunchAgent in
your graphical login session. The existing com.openabstractions.jobd label is
retained for upgrades; its command now hosts openabstractions serve runtime.
launchd restarts it after exit and removes its process group during shutdown.

The package includes openabstractions, jobd, dl and jobctl, Python packages and
~/.local/share/abstraction/uninstall.sh. It preserves application data.

Registration and process startup do not establish usable capability access.
The existing macOS Program identity-proof limitation still causes protected
service calls to refuse. This installer does not lower that requirement.

This package is unsigned and not notarised. Verify its published checksum and
source before installation.
