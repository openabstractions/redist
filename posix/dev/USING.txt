Building against these layers.

Go — nothing here to install; the modules resolve on their own.

    go get github.com/openabstractions/abstraction-facade/go

Python — the generated service clients come from the same registry every other
Python package does. This package carries none.

C++ — the over_curl header is not in this package. It publishes from no
repository yet, so there is nothing here to point at and nothing to include.

openabstractions in ~/.local/bin is built from these same layers. Its download
and jobs commands submit and observe work through the resolved runtime services
an application uses; anything they do, your program can do.
