Building against these layers.

Go — nothing here to install; the modules resolve on their own.

    go get github.com/openabstractions/abstraction-download/go
    go get github.com/openabstractions/abstraction-job/go
    go get github.com/openabstractions/abstraction-facade/go

Python — two packages. If python\job and python\download are beside this file,
install from them; a release package carries neither, and they come from the
same registry every other Python package does.

    pip install .\python\job
    pip install .\python\download

C++ — one header, no library and no dependency beyond curl on PATH. If
include\abstraction\ is beside this file, include from it; a release package
omits this optional header. Its declared home is abstraction-download-over-curl,
but no public commit was available at the 2026-09-12 check. This curl adapter
is separate from the generated service clients and shared IPC runtime.

    cl /std:c++17 /I .\include yourprogram.cpp

The tools in ..\tools\ are built from these same layers. dl is what the download
layer looks like from a shell; anything dl does, your program can do.
..\examples\ runs three of them against this install, and needs no checkout.
